# Citation style

`bioinformatics.csl` renders every citation in this repository.

## Provenance

Derived from the Bioinformatics journal style published in the Zotero style
repository (<http://www.zotero.org/styles/bioinformatics>), by Julian Onions with
contributions from Sebastian Karcher. The upstream `<info>` block is preserved
verbatim, including author contact and the licence grant; the attribution clause
requires it.

Local change: the `<title>` element was renamed to a neutral value. The formatting
rules are unmodified.

## Why it is vendored

Rendering must not depend on a path outside the repository. A checkout on any
machine reproduces identical citations from this copy.

Substituting a different journal style means replacing this file; no formatting rule
is written anywhere else.
