# Request

Add the xylulose-5-phosphate phosphoketolase reaction to the E. coli model, same
`xfp` gene as the F6P version.

It takes D-xylulose 5-phosphate and inorganic phosphate and produces acetyl-phosphate
and glyceraldehyde-3-phosphate. Call it `PKETX`, cytosolic, irreversible forward,
bounds 0 to 1000, gene rule `xfp`.

The model is in `examples/add-reaction/model/`.
